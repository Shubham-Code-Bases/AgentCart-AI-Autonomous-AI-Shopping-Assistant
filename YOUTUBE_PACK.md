## Video Description (Copy & Paste)

```text
AgentCart AI turns a natural-language shopping request into a policy-checked, evidence-cited purchase and a transparent receipt — built on the PayPal v2 Checkout API (OAuth2 -> create order -> capture) for the PayPal AI Hackathon 2026.

The autonomous commerce loop executes across 8 distinct phases:
PERCEIVE -> SEARCH -> SELECT -> POLICY -> APPROVAL -> EXPLAIN -> EXECUTE -> CAPTURE -> RECEIPT.

Money never moves before the deterministic spending policy engine runs. Every phase returns field-level evidence, allowing buyers and reviewers to audit why money did (or did not) move.

Key Features & Surfaces:
• AI Shopping Console: Natural-language request input, evidence ranking, and human pre-approval thresholds. The model proposes; policy disposes.
• Purchase Security Audit Grid (AG Grid): Evaluates every catalog item against guardrails in real time. Drag the "Simulated daily spend" slider to see limits trigger live.
• Subscription Intelligence: Proactively detects stealth price hikes (e.g. Netflix $15.49 -> $22.99), flags duplicate billings ($59.99 charges days apart), and generates polite dispute letters.
• Zero Third-Party Dependencies: Pure Python 3 standard library with 172 automated offline assertions. Runs out of the box with zero credentials.
```
